# CIS-228 Side Projects – Todo API

A read-only REST API for todo items, built for CIS-228 with Django 6.1 and Django REST Framework. Each todo has an `id`, `title`, and `body`, and the API has two endpoints: `GET /api/` lists all todos and `GET /api/<id>/` returns a single todo, or a 404 if it doesn't exist. Todos are added and edited through the Django admin at `/admin/`. To run it locally, create and activate a virtual environment, run `pip install -r requirements.txt`, then `python manage.py migrate`, `python manage.py createsuperuser`, and `python manage.py runserver`.
